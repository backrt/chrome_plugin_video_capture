# 视觉素材说明

- `logo-300.png`：300×300，所有商店语言可复用。
- `promo-small-440x280.png`：440×280，小型宣传图。
- `promo-large-1400x560.png`：1400×560，大型宣传图。
- `screenshots/<locale>/`：每种语言 3 张 1280×800 截图，依次展示未录制、录制中和保存成功状态。
- `source/render.html`：素材渲染源，界面内容取自当前插件的真实布局、状态和本地化文案。

截图中的播放器是无第三方品牌的示意背景，插件面板只展示当前版本已有的功能，不表示可以绕过网站限制或 DRM。
