# Firefox Add-ons 商店文案

## 简体中文（zh-CN）

名称：视频录制机

摘要：录制网页中实际播放的 HTML5 视频，并在本地生成支持拖动进度的 WebM 文件。

完整描述：

**视频录制机**是一款由用户主动控制的网页视频录制工具。播放网页中的普通 HTML5 视频后，点击扩展即可从当前位置开始录制实际播放的画面和声音。

点击“停止并保存”后，扩展会在 Firefox 本地整理录制分片、写入正确时长和定位索引，并将 WebM 文件保存到下载目录。兼容播放器可以直接拖动生成文件的进度条。

主要特点：

- 只录制用户开始录制后实际播放的内容。
- 视频暂停、缓冲、拖动或结束时，录制同步暂停。
- 切换标签页不会主动中断仍在播放的视频录制。
- 不会自动播放、跳转、静音或修改页面视频倍速。
- 视频分片、临时文件和诊断信息仅在本机 Firefox 中处理。
- 不包含分析、广告、追踪、账号或云上传功能。

本扩展不是原始媒体下载器，不会补录未观看区段，也不会绕过 DRM、订阅、付费墙、访问控制或网站保护。受保护媒体可能无法录制、黑屏或没有声音。请仅录制自行创作、已获授权、属于公有领域或法律允许保存的内容，并遵守网站条款和当地法律。

建议标签：视频录制、HTML5 视频、WebM、本地保存

截图说明：

1. 从当前播放位置开始录制，所有处理均在本地完成。
2. 录制状态跟随视频的实际播放、暂停与缓冲。
3. 停止后生成带时长和定位索引的 WebM 文件。

## 繁體中文（zh-TW）

名稱：影片錄製機

摘要：錄製網頁中實際播放的 HTML5 影片，並在本機建立可拖曳定位的 WebM 檔案。

完整描述：

**影片錄製機**是一款由使用者主動控制的網頁影片錄製工具。播放網頁中的一般 HTML5 影片後，點選擴充功能即可從目前位置開始錄製實際播放的畫面與聲音。

按下「停止並儲存」後，擴充功能會在 Firefox 本機整理錄製分段、寫入正確時長與定位索引，並將 WebM 檔案儲存至下載資料夾。相容播放器可直接拖曳產生檔案的進度列。

主要功能：

- 只錄製使用者開始錄製後實際播放的內容。
- 影片暫停、緩衝、拖曳或結束時，錄製同步暫停。
- 切換分頁不會主動中斷仍在播放的影片錄製。
- 不會自動播放、跳轉、靜音或修改頁面影片播放速度。
- 影片分段、暫存檔案與診斷資訊只在本機 Firefox 中處理。
- 不包含分析、廣告、追蹤、帳號或雲端上傳功能。

本擴充功能不是原始媒體下載器，不會補錄未觀看區段，也不會繞過 DRM、訂閱、付費牆、存取控制或網站保護。受保護媒體可能無法錄製、出現黑畫面或沒有聲音。請僅錄製自行創作、已獲授權、屬於公有領域或法律允許儲存的內容，並遵守網站條款與當地法律。

建議標籤：影片錄製、HTML5 影片、WebM、本機儲存

截圖說明：

1. 從目前播放位置開始錄製，所有處理都在本機完成。
2. 錄製狀態跟隨影片的實際播放、暫停與緩衝。
3. 停止後建立包含時長與定位索引的 WebM 檔案。

## English (en-US)

Name: Video Recorder

Summary: Record HTML5 video as it plays and save a local, seekable WebM file.

Full description:

**Video Recorder** is a user-controlled tool for recording ordinary HTML5 video as it actually plays on the current webpage. Start playback, open the extension, and record from the current position.

When you select “Stop and save,” the extension processes recorded chunks locally in Firefox, writes accurate duration and seek indexes, and saves a WebM file to your downloads folder. Compatible players can seek through the generated file.

Key features:

- Records only content actually played after the user starts recording.
- Pauses with the source while it is paused, buffering, seeking, or ended.
- Continues across tab switches while the original video continues playing.
- Never automatically plays, seeks, mutes, or changes playback speed.
- Processes video chunks, temporary files, and diagnostics locally in Firefox.
- Contains no analytics, advertising, tracking, accounts, or cloud uploads.

This extension is not an original-media downloader. It does not reconstruct unviewed portions or bypass DRM, subscriptions, paywalls, access controls, or website protections. Protected media may be unavailable, black, or silent in a recording. Use it only for content you created, are authorized to save, is in the public domain, or may otherwise lawfully record. You are responsible for applicable laws and website terms.

Suggested tags: video recording, HTML5 video, WebM, local recording

Screenshot captions:

1. Start recording from the current playback position with local-only processing.
2. Recording follows actual playback, pauses, and buffering.
3. Stop and create a WebM file with duration and seek indexes.

## 日本語（ja-JP）

名称：ビデオレコーダー

要約：ウェブで実際に再生した HTML5 動画を録画し、シーク可能な WebM をローカル保存します。

完全な説明：

**ビデオレコーダー**は、現在のウェブページで実際に再生されている一般的な HTML5 動画を、利用者の操作によって録画するツールです。動画を再生し、拡張機能を開くと、現在の位置から録画を開始できます。

「停止して保存」を選ぶと、録画データを Firefox 内で処理し、正確な再生時間とシーク用インデックスを含む WebM ファイルをダウンロードフォルダーに保存します。対応プレーヤーでは生成したファイルの再生位置を移動できます。

主な機能：

- 録画開始後に実際に再生された内容だけを記録します。
- 元の動画が一時停止、バッファリング、シーク、終了すると録画も一時停止します。
- 別のタブへ移動しても、元の動画が再生中なら録画を継続します。
- 自動再生、シーク、ミュート、再生速度の変更は行いません。
- 動画データ、一時ファイル、診断情報は Firefox 内だけで処理します。
- 分析、広告、追跡、アカウント、クラウド送信機能はありません。

本拡張機能は元メディアのダウンローダーではありません。未視聴区間の補完や、DRM、購読制限、ペイウォール、アクセス制御、サイト保護の回避は行いません。保護された動画は録画できない、黒画面になる、または音声が含まれない場合があります。自作、許可取得済み、パブリックドメイン、その他法律上録画可能なコンテンツにのみ使用し、適用法とサイト規約を守ってください。

推奨タグ：動画録画、HTML5 動画、WebM、ローカル保存

スクリーンショット説明：

1. 現在の再生位置から開始し、録画データをローカルで処理します。
2. 実際の再生、一時停止、バッファリングに合わせて録画します。
3. 停止後、再生時間とシーク用インデックスを持つ WebM を作成します。

## 한국어（ko-KR）

이름: 비디오 녹화기

요약: 웹에서 실제로 재생한 HTML5 동영상을 녹화하고 탐색 가능한 WebM 파일로 로컬 저장합니다.

전체 설명:

**비디오 녹화기**는 현재 웹페이지에서 실제로 재생되는 일반 HTML5 동영상을 사용자의 명시적인 조작으로 녹화하는 도구입니다. 동영상을 재생하고 확장 프로그램을 열면 현재 위치부터 녹화를 시작할 수 있습니다.

“중지하고 저장”을 선택하면 녹화 데이터를 Firefox 안에서 로컬로 처리하고 정확한 재생 시간과 탐색 인덱스가 포함된 WebM 파일을 다운로드 폴더에 저장합니다. 호환 플레이어에서는 생성된 파일의 재생 위치를 이동할 수 있습니다.

주요 기능:

- 사용자가 녹화를 시작한 뒤 실제로 재생한 내용만 기록합니다.
- 원본 동영상이 일시 정지, 버퍼링, 탐색 또는 종료되면 녹화도 일시 정지합니다.
- 다른 탭으로 전환해도 원래 동영상이 계속 재생되면 녹화를 유지합니다.
- 자동 재생, 탐색, 음소거 또는 재생 속도 변경을 하지 않습니다.
- 동영상 조각, 임시 파일 및 진단 정보는 Firefox 안에서만 처리합니다.
- 분석, 광고, 추적, 계정 또는 클라우드 업로드 기능이 없습니다.

이 확장 프로그램은 원본 미디어 다운로드 도구가 아닙니다. 시청하지 않은 구간을 복원하거나 DRM, 구독 제한, 유료 장벽, 접근 제어 또는 웹사이트 보호를 우회하지 않습니다. 보호된 미디어는 녹화되지 않거나 검은 화면 또는 무음으로 저장될 수 있습니다. 직접 제작했거나 저장 권한을 받은 콘텐츠, 퍼블릭 도메인 콘텐츠 또는 법적으로 녹화 가능한 콘텐츠에만 사용하고 관련 법률과 사이트 이용 약관을 준수하세요.

권장 태그: 동영상 녹화, HTML5 동영상, WebM, 로컬 저장

스크린샷 설명:

1. 현재 재생 위치부터 시작하며 모든 녹화 데이터를 로컬에서 처리합니다.
2. 실제 재생, 일시 정지 및 버퍼링 상태에 맞춰 녹화합니다.
3. 중지 후 재생 시간과 탐색 인덱스가 포함된 WebM 파일을 만듭니다.
